# Finish the Lyrics — Musical Quest for Sir H

A single-player Musical Intelligence game: two YouTube songs play with synced karaoke lyrics and pause at 8 missing lyrics each for the player to fill in. Created by Jessamae Moldero.

**Tech:** TanStack Start (React 19), Tailwind CSS 4, YouTube IFrame Player API, Netlify Blobs (host-saved config), Netlify.

**Run locally:** `npm install` then `netlify dev` (set `HOST_PIN` to use /host saving).

**Edit lyrics:** defaults in `src/data/songs.ts`; live edits at `/host`.

**Roadmap:** see `PLAN.md` (type/lint pass, timing fine-tune, full device playthrough).
